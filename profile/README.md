# Spoutcodes
### An efficeient web development company.
## What type of projects do we do?
### Web apps
Applications that can be freely opened in a web browser without requiring to download anything.
### Local Apps
Applications that you install and run locally.
### Hobbyist's projects
Coding as a hobby is cool. Here in spoutcodes we code an idea and send it out to the world as an open scource project!
### What license do we use?
We use the MIT license, common for open scource projects and gives mobility of changes.
### When do we not accept forks?
We do not accept forks that are an exact copy of our repository or malicious copies with malicious code injected to perform malicious actions such as download files or run adware.
If you do not follow these rules your repository will be reported and will be taken down.
If you spot a library that does not follow one of these rules, please create an issue on the original repository and I will take the malicious repository down if possible.
